  about
</h2>

**rezzt.modz** is an independent minecraft modding studio. every project is open source under the mit license and built around three principles: server-side friendly, fully configurable, and respectful of the vanilla experience.

the catalog covers gameplay overhauls, server administration tools and performance-focused utilities for minecraft java edition — mostly targeting **1.20.1 (forge)**, with newer editions on **neoforge** and **fabric**.

- **server-side first** — several mods run only on the server; vanilla clients can join without installing anything.
- **configurable by design** — every lever is exposed through json/toml configs or in-game config screens.
- **vanilla-friendly** — mechanics that extend the base game instead of replacing it.

**sobre nosotros**

**rezzt.modz** es un estudio independiente de desarrollo de mods de minecraft. todos los proyectos son de codigo abierto bajo la licencia mit y se construyen sobre tres principios: compatibles con el lado del servidor, totalmente configurables y respetuosos con la experiencia vanilla.

el catalogo cubre revisiones de jugabilidad, herramientas de administracion de servidores y utilidades de rendimiento para minecraft java edition, principalmente para **1.20.1 (forge)** y con ediciones mas recientes en **neoforge** y **fabric**.

- **servidor primero** — varios mods funcionan solo en el servidor; los clientes vanilla pueden entrar sin instalar nada.
- **configurables desde el principio** — cada opcion se expone mediante archivos json/toml o pantallas de configuracion dentro del juego.
- **fieles a vanilla** — mecanicas que extienden el juego base en lugar de reemplazarlo.

all mods are written in **java (17 and 21)** and built with **gradle**, using multi-loader scaffolds based on **unimined** and **architectury**, **mixin / mixinextras** for vanilla hooks, and official **mojang mappings**. flagship projects ship with automated builds and in-game test suites (`rungradlew rungametestserver`) wired into ci.
